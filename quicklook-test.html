QUICK LOOK EXPERIMENT 01

West Coast Naturals
Apple AR test

This test uses Apple's native AR Quick Look rather than the drifting WebAR engines. It uses the real Heartwood LAP texture from the LUX repository.

Source texture: Heartwood/LAP HEARTWOOD.jpg. Fixed UV mapping — never tiled.
PREPARING USDZ…

Creating a self-contained native AR file using the existing woodgrain.

Save USDZ to Files (alternative launch)
1. Open in Safari on iPhone and tap OPEN APPLE AR.
2. Use AR mode and position the sample on the actual wall.
3. Tap the four white squares on the model. Each is linked to a separate edge-reveal action.
4. Walk sideways and back to test native tracking.

This first USDZ experiment tests native wall anchoring and four one-step tap controls. Dragging, full-profile geometry, multiple colours and repeating expansion steps are not yet implemented. We need to confirm that Apple runs the embedded actions on your device.
