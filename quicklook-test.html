How to test

  1. Open this page in Safari on the iPhone.
  2. Try Test A first. Does the red cube open? Can you place it in AR against a wall?
  3. If Test A works, try Test B. Can you see the woodgrain model and four white markers?
  4. Tap the markers and see whether they reveal additional woodgrain without closing AR.

The four controls are experimental, one-step actions—not continuous draggable handles yet. If Test A fails, the issue is loading, packaging or Quick Look itself; if A works but B fails, the issue is in our materials/behaviors. Neither result should be mistaken for production readiness.
